# Permissions and fair use

RETRANS restreams a source you provide to **your** X / RTMP destination. You are responsible for the rights to do that.

Wave 1 is live YouTube → operator RTMP (X Media Studio). The same rules apply to later sources.

---

## Only restream what you have rights to

Go-live is allowed only when **you** have the right or explicit permission to restream that source to X.

That means, at minimum:

- You own the live, **or**
- The rights holder authorized this restream, **or**
- Another written license clearly covers live restream to X.

“I found a public URL” is not permission.

---

## Fair use is not a blanket license

Fair use / fair dealing is a narrow, fact-specific defense — not a default license to restream someone else’s live.

Do not treat these as sufficient on their own:

- The source is public on YouTube.
- You will add commentary later.
- You will only restream “a short time.”
- You believe the use is newsworthy.

If you are relying on fair use, that is **your** legal call, documented **before** start. RETRANS does not grant rights.

---

## Operator confirmation before go-live

The operator must confirm permission / fair-use acknowledgment **before** start. No confirmation → no restream.

Confirmation is per go-live (or a recorded policy the operator re-affirms). It is not implied by pasting a URL.

---

## Platform terms (operator must follow)

Official terms — read the current page before go-live:

- [YouTube Terms of Service](https://www.youtube.com/t/terms)
- [YouTube Community Guidelines](https://www.youtube.com/howyoutubeworks/policies/community-guidelines/)
- [X Terms of Service](https://x.com/tos)
- [X Rules](https://help.x.com/en/rules-and-policies/x-rules)

If a link above 404s or moves, use the current official YouTube / X policy URL. Do not restream in a way those terms forbid.
